API Reference
=============

Complete API documentation for ``imgproxykit``. For step-by-step explanations
and examples, see the :doc:`User guide <../user-guide/client>`.

* :doc:`client` — URL generation and client configuration.
* :doc:`transform` — transformation arguments and processing options.
* :doc:`Options <options>` — built-in option classes and their arguments.
* :doc:`types` — supported values and type aliases.
* :doc:`extensions` — custom path serialization and URL signing.
* :doc:`django` — optional Django settings, shortcuts, and source resolution.
* :doc:`drf` — optional Django REST Framework serializer fields.
* :doc:`fastapi` — optional FastAPI client registration and dependencies.
